# Kenedy Muange Nguli — Professional Portfolio

A responsive, single-page portfolio for **Kenedy Muange Nguli**, a Community Development practitioner and field research professional.

## Sections
- Professional introduction
- About and core strengths
- Skills and digital data collection tools
- Professional experience
- Selected community and research focus areas
- Education and contact links

## Built with
HTML, CSS, and a small amount of vanilla JavaScript. No build step or external dependencies are required.

## View locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Personalise before sharing
Review the experience descriptions and contact links to ensure all details are current. You can add a professional headshot, project photos, reports, or downloadable CV when ready.
